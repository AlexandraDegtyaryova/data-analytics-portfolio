# Дашборд TED-конференций

[← Все проекты](../../README.md)

## Задача

Представить аналитику TED-конференций в интерактивном дашборде.

## Что сделано

Визуализация и представление аналитики в DataLens.

## Инструменты и навыки

DataLens, дашборды, визуализация данных.

## Результат

В исходном документе сохранена ссылка на дашборд. Экспорт его настроек и исходные данные не приложены.

## Данные и запуск

Для просмотра используется DataLens; доступность внешней ссылки зависит от настроек публикации.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.
