# Отток клиентов банка

[← Все проекты](../../README.md)

## Задача

Выделить характеристики клиентов, связанные с оттоком из банка «Метанпром», и предложить направления удержания.

## Что сделано

Объединение таблиц, очистка данных, анализ распределений и взаимосвязей, сравнение клиентских сегментов.

## Инструменты и навыки

Python, pandas, matplotlib, seaborn, phik, EDA.

## Результат

Сформирован профиль ушедших клиентов и предложены меры удержания с учётом возраста, программы лояльности и числа используемых продуктов.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

В ноутбуке указаны URL учебных файлов `bank_information.csv` и `clients_information.csv`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
