# Исследование ДТП в Кировской области

[← Все проекты](../../README.md)

## Задача

Исследовать данные «Карты ДТП» и взаимосвязи между авариями, погодой, освещённостью и характеристиками участников.

## Что сделано

Изучение распределений и выбросов, корреляций, категорий аварий и сравнений групп с пострадавшими и без них.

## Инструменты и навыки

Python, pandas, matplotlib, seaborn, Google Colab, EDA.

## Результат

Ноутбук содержит учебный разбор аварийности, визуализации и обсуждение ограничений качества данных.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

Нужны `Kirovskaya_oblast.csv` и `Kirovskaya_oblast_participiants.csv` (написание сохранено из кода). Используются Google Colab, подключение Drive и пути `/content/`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.

В локальном Jupyter также потребуется адаптировать ячейку `google.colab` и подключение Google Drive.
