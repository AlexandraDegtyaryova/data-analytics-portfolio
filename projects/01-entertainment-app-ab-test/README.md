# A/B-тест рекомендательной системы

[← Все проекты](../../README.md)

## Задача

Спланировать эксперимент и оценить влияние нового алгоритма рекомендаций на долю успешных сессий развлекательного приложения.

## Что сделано

Анализ исторических данных, выбор целевой метрики, расчёт параметров эксперимента, проверка результатов A/B-теста и рекомендация по внедрению.

## Инструменты и навыки

Python, pandas, NumPy, matplotlib, statsmodels, A/B-тестирование.

## Результат

В итоговом выводе ноутбука статистически значимое изменение метрики не подтверждено; предложено не внедрять новый алгоритм
