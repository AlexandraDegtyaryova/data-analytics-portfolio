# A/B-тест рекомендательной системы

[← Все проекты](../../README.md)

## Задача

Спланировать эксперимент и оценить влияние нового алгоритма рекомендаций на долю успешных сессий развлекательного приложения.

## Что сделано

Анализ исторических данных, выбор целевой метрики, расчёт параметров эксперимента, проверка результатов A/B-теста и рекомендация по внедрению.

## Инструменты и навыки

Python, pandas, NumPy, matplotlib, statsmodels, A/B-тестирование.

## Результат

В итоговом выводе ноутбука статистически значимое изменение метрики не подтверждено; предложено не внедрять новый алгоритм.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

Для повторного запуска нужны `sessions_project_history.csv`, `sessions_project_test_part.csv`, `sessions_project_test.csv`. В ноутбуке используются пути `/datasets/`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
