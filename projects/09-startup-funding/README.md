# Исследование финансирования стартапов

[← Все проекты](../../README.md)

## Задача

Проанализировать динамику и структуру финансирования стартапов по сегментам рынка и типам инвестиций.

## Что сделано

Предобработка числовых и временных данных, анализ выбросов, категоризация сегментов, сравнение раундов и объёмов финансирования, анализ возврата средств.

## Инструменты и навыки

Python, pandas, matplotlib, seaborn, EDA.

## Результат

Сопоставлены сегменты и типы финансирования, изучена динамика вложений и сформулированы выводы по учебным данным.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

В ноутбуке указаны URL `cb_investments.zip` и `cb_returns.csv`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
