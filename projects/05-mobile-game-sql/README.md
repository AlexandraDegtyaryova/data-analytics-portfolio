# Монетизация игры «Секреты Тёмнолесья»

[← Все проекты](../../README.md)

## Задача

Изучить долю платящих игроков, внутриигровые покупки и различия покупательской активности между расами персонажей.

## Что сделано

Расчёт долей и статистик покупок, анализ нулевых транзакций, популярности предметов и сегментов игроков; решение ad hoc-задачи.

## Инструменты и навыки

SQL, PostgreSQL, CTE, JOIN, оконные функции.

## Результат

Подготовлены SQL-запросы и аналитический отчёт с выводами по покупкам и предложениям для игровых сегментов.

- [analysis.sql](analysis.sql)

## Данные и запуск

Запросы используют учебную схему `fantasy`. Дамп базы данных в исходной папке отсутствует.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.
