# Рынок общественного питания Москвы

[← Все проекты](../../README.md)

## Задача

Изучить структуру рынка общепита Москвы и сформулировать рекомендации по формату и размещению заведения.

## Что сделано

Объединение сведений о заведениях и ценах, предобработка, сравнение категорий, округов, рейтингов, сетевых и несетевых заведений.

## Инструменты и навыки

Python, pandas, NumPy, matplotlib, seaborn, phik, EDA.

## Результат

Подготовлены рекомендации по выбору формата и локации с учётом конкуренции, среднего чека и рейтингов.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

Для повторного запуска нужны `rest_info.csv` и `rest_price.csv`. В ноутбуке используются пути `/datasets/`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
