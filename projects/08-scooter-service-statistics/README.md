# Сервис самокатов GoFast: проверка гипотез

[← Все проекты](../../README.md)

## Задача

Исследовать пользователей и поездки сервиса самокатов и проверить статистические гипотезы.

## Что сделано

Обработка и объединение данных о пользователях, поездках и подписках, статистические проверки, работа с распределениями и квантилями.

## Инструменты и навыки

Python, pandas, matplotlib, SciPy, статистический анализ.

## Результат

Подготовлен учебный анализ поездок и подписок со статистическими проверками и расчётами на основе распределений.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

В ноутбуке указаны URL файлов `users_go.csv`, `rides_go.csv` и `subscriptions_go.csv`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
