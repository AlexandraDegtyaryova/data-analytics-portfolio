# Рынок недвижимости Санкт-Петербурга и Ленинградской области

[← Все проекты](../../README.md)

## Задача

Исследовать длительность размещения объявлений, сезонность и различия локальных рынков недвижимости.

## Что сделано

SQL-запросы с объединениями таблиц, CTE, фильтрацией выбросов по перцентилям, сегментацией и агрегированием.

## Инструменты и навыки

SQL, PostgreSQL, CTE, DataLens.

## Результат

Подготовлены SQL-анализ, отчёт в PDF и ссылка на интерактивный дашборд
