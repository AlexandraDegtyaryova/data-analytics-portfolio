# Книжный сервис: гипотезы и A/B-тест

[← Все проекты](../../README.md)

## Задача

Сравнить активность читателей Москвы и Санкт-Петербурга и проанализировать эксперимент по изменению конверсии.

## Что сделано

Сравнение выборок и распределений, односторонняя проверка гипотезы, оценка размера выборки, анализ конверсии и z-тест пропорций.

## Инструменты и навыки

Python, pandas, NumPy, SciPy, statsmodels, matplotlib.

## Результат

В ноутбуке представлены проверка гипотезы об активности читателей и оценка результатов A/B-теста с сопоставлением эффекта с целевым.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

Нужен `yandex_knigi_data.csv` (путь `/datasets/`). Для `ab_test_participants.csv` и `ab_test_events.zip` в ноутбуке указаны URL.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
