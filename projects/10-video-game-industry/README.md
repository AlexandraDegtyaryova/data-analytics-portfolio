# Анализ игровой индустрии

[← Все проекты](../../README.md)

## Задача

Подготовить и исследовать данные об играх для команды «Секреты Темнолесья».

## Что сделано

Проверка типов данных, пропусков и дубликатов; выделение периода 2000–2013 годов; категоризация оценок пользователей и критиков, сравнение платформ.

## Инструменты и навыки

Python, pandas, очистка данных, категоризация.

## Результат

Сформирован срез по выбранному периоду, добавлены категории оценок и рассмотрены ведущие платформы
