# Анализ игровой индустрии

[← Все проекты](../../README.md)

## Задача

Подготовить и исследовать данные об играх для команды «Секреты Темнолесья».

## Что сделано

Проверка типов данных, пропусков и дубликатов; выделение периода 2000–2013 годов; категоризация оценок пользователей и критиков, сравнение платформ.

## Инструменты и навыки

Python, pandas, очистка данных, категоризация.

## Результат

Сформирован срез по выбранному периоду, добавлены категории оценок и рассмотрены ведущие платформы.

## Материалы

- [analysis.ipynb](analysis.ipynb)

## Данные и запуск

Для повторного запуска нужен `new_games.csv`. В ноутбуке используется путь `/datasets/new_games.csv`.

Исходные датасеты и дампы БД в репозиторий не включены: их нет среди переданных материалов.

Ноутбук можно открыть на GitHub с сохранёнными результатами выполнения. Для запуска установите библиотеки из `requirements.txt`, подготовьте данные и проверьте пути к ним. Версии зависимостей в исходных материалах не зафиксированы; совместимость конкретного окружения не проверялась.
